# zbot-pixel: legacy model, NOT the Pixel-01 robot

This folder is older than the robot's name Pixel-01 (2026-11-28) and does not describe the built robot. It was generated
from the K-Scale Z-Bot 2 assets (see `sim/README.md`, section on the wrong models) and was used only by the early runs
`run_0` and `backpack_v1`–`v10` (Sept 2026). The model of Pixel-01 is `sim/assets/zbot-cad-tpu`.

The folder keeps its name because scripts and old run configs refer to it.
